# Security Policy

## Supported version

The latest commit on `main` and the latest GitHub release are supported.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/bchop-studio/hermes-liquid-glass/security/advisories/new) for security-sensitive reports.

Do not open a public issue for a suspected vulnerability. Include the affected version, reproduction steps, impact, and any suggested fix. Reports will be reviewed before details are made public.

## Scope

Hermes Liquid Glass is a local Hermes Desktop plugin. Security reports may cover the plugin source, palette generator, release builder, packaged archive, installation instructions, or repository automation.
